# 2026 CUMCM B题：无线电干扰源的快速自动定位与清除

本项目包含 2026 年全国大学生数学建模竞赛 B 题的完整数学建模、高保真本地仿真模拟器及各小题算法求解程序。

  - 模拟器快速上手与 CLI 命令行参数
  - 核心物理模型、测向误差锥与朝向无关激光清除判定
  - 严格虚拟时间计费状态机与幂等性机制
  - 官方评测 HTTP 协议标准与 REST 控制接口规范
  - 战术态势 WebUI 交互、算法进程调度与防崩溃历史录像回放
- [问题求解脚本与算法原理说明]

  - `P3.py`：第三题多信道全向干扰源全局快速搜索与清除主程序（详见 [p3/P3_explanation.md](./p3/P3_explanation.md)）
